# Sin Senos Sí Hay Paraíso — Guía de fans React

## Inicio
```powershell
npm install
npm run dev
```
Abrir http://localhost:5173

Incluye 8 retratos promocionales enlazados desde el artículo oficial de Telemundo (las imágenes se cargan por Internet, no se distribuyen en el ZIP), 12 fichas de personajes, 6 etapas, videos iniciales de YouTube y perfil TikTok @johanlenin0. Algunas fotos de personajes secundarios dependen de Wikimedia Commons. No es un archivo completo de todos los capítulos; los enlaces adicionales conducen a búsquedas de YouTube o al sitio oficial.
